# Objective

Build the Artifact Viewer.

The Artifact Viewer is the central place where users inspect every output generated by the Prometheus Swarm.

Artifacts are first-class citizens.

Every output produced during a mission should be discoverable, previewable, searchable and understandable.

The user should immediately know:

* What this artifact is
* Which mission produced it
* Which agent created it
* When it was generated
* What depends on it

No backend implementation.

Everything uses realistic mock data.

---

# Scope

Frontend only.

Do NOT implement:

* File storage
* Downloads
* Upload backend
* Version control backend
* AI execution
* Database logic

Everything should use static mock data.

This task is complete only when:

* Artifact list page is complete.

* Compare dialog is implemented.

* Comments UI exists.
* Responsive behavior is complete.
* Theme support works.
* Accessibility requirements are met.
