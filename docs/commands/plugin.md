# Plugin Commands

## `plugin inspect`
Inspect a specific plugin.
- **Category:** Plugin
- **Tier:** 2
- **Implemented:** ✓
- **Aliases:** `plugins inspect`
- **Examples:**
  - `prometheus prometheus plugin inspect my-plugin`
- **Related:** `plugin list`

## `plugin list`
List all registered plugins.
- **Category:** Plugin
- **Tier:** 2
- **Implemented:** ✓
- **Aliases:** `plugins list`
- **Examples:**
  - `prometheus prometheus plugin list`
- **Related:** `plugin inspect`
