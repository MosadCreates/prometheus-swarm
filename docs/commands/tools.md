# Tools Commands

## `tool inspect`
Inspect a specific tool.
- **Category:** Tools
- **Tier:** 2
- **Implemented:** ✓
- **Examples:**
  - `prometheus prometheus tool inspect scout.load_data`
- **Related:** `tool list`

## `tool list`
List all registered tools.
- **Category:** Tools
- **Tier:** 2
- **Implemented:** ✓
- **Aliases:** `tool ls`
- **Examples:**
  - `prometheus prometheus tool list`
- **Related:** `tool inspect`
