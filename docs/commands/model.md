# Model Commands

## `model export`
Export a trained model to ONNX or pickle format
- **Category:** Model
- **Tier:** 2
- **Implemented:** ✓
- **Aliases:** `mdl export`

## `model inspect`
Show model metadata, metrics, and evaluation results
- **Category:** Model
- **Tier:** 2
- **Implemented:** ✓
- **Aliases:** `mdl inspect`

## `model list`
List all trained models found in outputs/
- **Category:** Model
- **Tier:** 2
- **Implemented:** ✓
- **Aliases:** `mdl list`

## `model show`
Show model metadata, metrics, and evaluation results (alias for inspect)
- **Category:** Model
- **Tier:** 2
- **Implemented:** ✓
- **Aliases:** `mdl show`
