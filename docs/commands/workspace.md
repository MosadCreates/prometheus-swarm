# Workspace Commands

## `workspace init`
Mark a directory as a Prometheus workspace
- **Category:** Workspace
- **Tier:** 2
- **Implemented:** ✓
- **Aliases:** `ws init`

## `workspace list`
List known workspace directories
- **Category:** Workspace
- **Tier:** 2
- **Implemented:** ✓
- **Aliases:** `ws list`

## `workspace use`
Switch the active workspace by name or path
- **Category:** Workspace
- **Tier:** 2
- **Implemented:** ✓
- **Aliases:** `ws use`
