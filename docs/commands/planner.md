# Planner Commands

## `planner dry-run`
Compile a MissionSpecification into a plan and validate it (no execution)
- **Category:** Planner
- **Tier:** 2
- **Implemented:** ✓
- **Aliases:** `plan dry-run`

## `planner explain`
Show why the Planner estimated what it did for a job
- **Category:** Planner
- **Tier:** 2
- **Implemented:** ✓
- **Aliases:** `plan explain`

## `planner inspect`
Show the ExecutionPlan for a job
- **Category:** Planner
- **Tier:** 2
- **Implemented:** ✓
- **Aliases:** `plan inspect`

## `planner prediction-error`
Show prediction error history across jobs
- **Category:** Planner
- **Tier:** 2
- **Implemented:** ✓
- **Aliases:** `plan prediction-error`

## `planner stats`
Show aggregate execution statistics per architecture
- **Category:** Planner
- **Tier:** 2
- **Implemented:** ✓
- **Aliases:** `plan stats`

## `planner validate`
Run all 5 validators on an existing ExecutionPlan
- **Category:** Planner
- **Tier:** 2
- **Implemented:** ✓
- **Aliases:** `plan validate`
